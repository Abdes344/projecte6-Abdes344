# 🎓 T10: Canvas LMS, una alternativa a Moodle

## 📖 Breu descripció

Després d'haver desplegat i configurat una acadèmia virtual amb Moodle, el client ens ha sol·licitat estudiar una alternativa tecnològica que permeti oferir els mateixos serveis de formació en línia.

En aquesta pràctica treballarem amb **Canvas LMS**, una de les plataformes d'aprenentatge més utilitzades en universitats i organitzacions de tot el món.

Per facilitar el desplegament, utilitzarem la imatge preconfigurada de **TurnKey Linux Canvas**, que inclou els components necessaris per a la seva execució.

L'objectiu és instal·lar la plataforma, configurar una acadèmia virtual bàsica, crear cursos formatius, generar continguts amb intel·ligència artificial i gestionar usuaris dins de l'entorn educatiu.

---

# 🎯 Objectius del projecte

Durant aquesta activitat es treballaran els següents aspectes:

* ⚙️ Instal·lació i desplegament de Canvas LMS.
* 🖥️ Administració d'un entorn educatiu virtual.
* 📚 Creació de cursos i continguts.
* 🤖 Utilització d'IA generativa per a materials educatius.
* 👥 Gestió d'usuaris i matriculacions.
* 🌱 Integració de continguts relacionats amb Green IT i transformació digital.
